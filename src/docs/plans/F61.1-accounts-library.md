# F61.1 The accounts library

> **Plan** (a child of [F61](F61-accounts-and-azure.md), which holds the design, the four diagrams and the namespace
> map). How the framework gets `louis-agent.accounts`: ASP.NET Core Identity on EF Core and SQL Server, a tenant on
> every account from the host name, the `/account` routes and their contracts. Started 2026-11-07 on
> `feature/F61.1-accounts-library`, under the parent's approval of 2026-11-07. Deleted when the work is done.

## Done when

A host that calls `AddLouisAgentAccounts`, `UseLouisAgentAccounts` and `MapLouisAgentAccounts` registers, confirms,
signs in and reads `/account/me` against the Docker SQL Server, with the tenant on every user, and a second tenant can
hold the same email.

## Steps

The parent's *F61.1* section, one commit each, test first:

1. The projects and the user (`AccountUser`, `Tenant`; the solution groups).
2. The context and the first migration; `puls-sql` in the Puls compose; `dotnet ef` as a local tool.
3. The tenant from the host (`ITenantResolver`, `HostTenantResolver`, `CurrentTenant`, `TenantMiddleware`).
4. The store knows the tenant (`AccountUserStore`).
5. The mail seam (`LogEmailSender`).
6. Start-up (`AccountsOptions`, `AccountsStartup`).
7. Our routes and the contracts (`/account/me`, `logout`, `profile`, `DELETE /account`, `providers`).
8. Docs: the project doc, the settings, two ADRs, CI's SQL Server, the TODO, the write-up.

## Approved during the build

Picks taken unattended (Louis, 2026-11-07: "do all unattended"), each the recommended one of three:

- **A migration's files aren't sized** (step 2). EF Core writes a migration's `.cs`, its `.Designer.cs` and the model
  snapshot, each hundreds of lines nobody maintains by hand. Options: count them and split them (impossible, the tool
  rewrites them); `EnsureCreated` with no migrations (every schema change drops the accounts, which production can't
  take); **leave `Migrations/` out of `FileSizeTests` and `FolderSizeTests` as the build's output is** (picked: the
  size rule is for code a person maintains, ADR 0044, and a migration is a tool's record).

## Verification

`dotnet test src/tests/hosts/louis-agent.accounts.tests`; `dotnet test src/tests/hosts/louis-agent.accounts.integration-tests`
with `ACCOUNTS_SQL_TEST_URL` set to the Docker SQL Server (skipped honestly without it); `core.tests` for the solution
layout and the sizes. No paid run.
