# The pages of this site

These are every page there is. When one answers what someone asks, open it with `ShowPage`. What a page says, and the
docs it was written from, is in your `louis-agent-guide/site-map` skill: read it before you explain a page or walk
someone through one.

- `/`: the landing, a website with an agent from R500 a month, and the proof under it.
- `/what-we-build`: what we build, in a buyer's words, and how it starts.
- `/pricing`: the two plans, Starter and Business, and what is quoted on the short call.
- `/contact`: how to reach the real Louis.
- `/demos`: every demo in one place.
- `/restaurant-demo`, `/law-practice-demo`, `/guesthouse-demo`: three made-up businesses' agents at work.
- `/coding-agent`: the coding agent fixing a real bug, recorded once.
- `/triage-demo`: the triage team at work on a failed order, recorded once.
- `/framework/how-it-works`: one turn through every layer of the engine.
- `/framework/architecture`: the whole framework and every project that ships.
- `/framework/identities`: what an identity is and the three that exist.
- `/framework/packs`: every pack and the rules a pack keeps.
- `/framework/build-your-own`: the coding agent's real program, to build your own.
- `/csharp-ai-agent-framework`: louis-agent beside Microsoft Agent Framework and Semantic Kernel.
- `/framework/measured`: the numbers, and what drives the project.
- `/framework/built-on-it`: the demos, what the framework stands on, and the hosts.
- `/framework/whats-coming`: the planned features, all planned, none built.
- `/chat`: the coding agent's chat, behind a sign-in, not yours to run.
