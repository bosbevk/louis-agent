2 · The cataloguenew AgentCatalog(identities, packs)
  • An identity is who the agent is: voice, modes, roles, as markdown
  • A pack is what it can do, and ships as a package that needs only the contracts
  • The engine itself names no product
identity: coding agent · packs: files, git, dotnet
3 · Core, the model, a toolIChatClient · ToolCallGuards
  • One chat client across providers, and the provider is configuration
  • The pack holds the tool. The engine holds the guards: arguments are data, a result over 50,000 characters is summarised first

4 · The hosts, and the webAgentHost.Build() · AgentKeyGate
  • Every host is a library: a terminal, Rider's chat, the HTTP API, an MCP server
  • A site is a small app on the framework's web, served by the API from the same origin
  • A sign-in or a key before any session opens
Rider · API + web · CLI · MCP
5 · The evals, and the ledgerUsageLedger · PriceTable
  • Every check is a C# eval on one harness, beside what it proves. A stored run re-scores for nothing
  • Every model request is one record with its tokens and cost, from a dated price table. Unknown stays unknown
