# CL68.1 `prompts/` goes, `agent/` is `agents/`

A plan, for Louis's approval: CL68's first child. Every project's prompts lose their `prompts/` wrapper and sit at
the project's root, `agent/` becomes `agents/` everywhere it's named, and the showroom names each business once.
Six steps, one commit each, on `refactor/CL68.1-prompts-go-agents-is-agents`. The parent plan,
[CL68](CL68-agents-and-their-subagents.md), says why and draws the end state; this one says how.

![CL68.1 in six steps: the wrapper goes in every project, agent becomes agents, the showroom flat with one provider, the site's link, the headers' levels, then the docs](diagrams/CL68.1-prompts-go-agents-is-agents-overview.svg)

## Context

Louis, 2026-11-19: "this prompt structure needs to be called agents. prompts can go. and why does the showroom
have this structure". The parent plan was approved that day. It started again on 2026-11-22, after F170, and two
picks were made then:

- **Finding 0, A:** the louis-agent demo's two identities, the coding agent and the triage team, move with the
  engine in each child. The parent plan left the demos broken, which was for Puls; Puls has left the repository, the
  louis-agent demo stays, and every merge is on green.
- **CL68.1's finding 1, A:** each project embeds its prompt folders by name, `agents\**\*.md`, `toolsets\**\*.md`,
  `shared\**\*.md`, only the ones it has, and `EmbeddedPrompts.Of` reads from the project's root. No filter: the
  recipes and shop-prices packs, whose other files were the reason for one, left with Puls, and today every project
  embeds only its prompts.

What was read for this plan, on `main` at `5528099a3`. Seventeen projects embed `prompts\**\*.md` with
`GenerateEmbeddedFilesManifest`: core, the ten packs, the guide, the framework Orbi, the showroom, the core tests,
and the coding and triage identities. Every one reads them through `EmbeddedPrompts.Of(assembly)`, a
`ManifestEmbeddedFileProvider` rooted at `prompts`, except the showroom, which roots each of its three businesses
one folder deeper (`EmbeddedPrompts.Of(assembly, business)`) so the catalogue doesn't see each voice three times.
`RoleCatalog.AgentFolder` is `"agent"`, and `SkillFiles.FunctionsFolder` writes it out as `"agent/functions"`, which
the skill tools' descriptions tell the model, so a golden file holds it. `AgentCatalog` gathers every provider into
one list and checks every path in them is unique (lines 75 and 76). `LouisAgent.Site` links
`prompts\shared\principles.md` by path. The tests that read the layout from the disk are `PromptFolderTests`,
`SkillsLayoutTests`, `ArchitectureTests` (core's prompts), `EveryPromptHasAHeaderTests` (every pack's and identity's)
and `TestPaths.CorePrompts`. No agent-written skill sits in an `agent/functions/` folder on any disk this repository
knows, so nothing stored has to move (ADR 0049 would refuse a reader for the old place anyway).

## Design

### What moves

| Project | Today | After |
|---|---|---|
| Core | `prompts/shared/`, `prompts/toolsets/` | `shared/`, `toolsets/` |
| Each pack | `prompts/toolsets/` | `toolsets/` |
| The guide, the framework Orbi, the coding agent | `prompts/agent/{name}/` | `agents/{name}/` |
| The triage team | `prompts/agent/triage/`, `prompts/specialists/` | `agents/triage/`, `specialists/` (CL68.2 moves it) |
| The showroom | `prompts/{business}/agent/{business}/` | `agents/{business}/` |
| The core tests | `prompts/agent/testprod/`, `prompts/specialists/`, `prompts/minions/` | `agents/testprod/`, `specialists/`, `minions/` |

`specialists/` and `minions/` only lose the wrapper here; CL68.2 and CL68.3 move them inside their agent.

### How the engine reads them

Each `.csproj` embeds the prompt folders it has, by name, and `EmbeddedPrompts.Of(assembly)` reads the manifest from
the root, so a path in the project is the path the engine reads. `EmbeddedPrompts.Folder` goes, and so does the
subfolder overload: the showroom's three identities share one static provider over the whole project, and
`AgentCatalog` gathers its providers with `Distinct()`, so a provider it holds twice is read once and each voice
appears once. `RoleCatalog.AgentFolder` becomes `"agents"` and `SkillFiles.FunctionsFolder` `"agents/functions"`.

### What is reused

`ManifestEmbeddedFileProvider`'s constructor with no root folder
([its constructors](https://learn.microsoft.com/en-us/dotnet/api/microsoft.extensions.fileproviders.manifestembeddedfileprovider.-ctor)),
the header reader (ADR 0063), and `git mv` for every file, so each keeps its history. No package is added.

## Steps

One commit each, its test written first and seen failing; a review stop after each.

1. **The wrapper goes, in every project.** Each project's `prompts/` content moves up to its root with `git mv`,
   each `.csproj` embeds its folders by name, `EmbeddedPrompts.Of` reads the root and `Folder` goes, and the readers
   of the disk (`SkillFileSource`, `TestPaths.CorePrompts`, `ArchitectureTests`, `SkillsLayoutTests`) follow. A pure
   move plus one constructor: the diff is renames and a few lines. Test: `PromptFolderTests` holds that no project
   outside `demos/` and none in it has a `prompts/` folder or names one; it fails first on all seventeen.
2. **`agent/` is `agents/`.** Every identity's and the core tests' `agent/` folder becomes `agents/`,
   `RoleCatalog.AgentFolder` and `SkillFiles.FunctionsFolder` follow, and the skill tools' descriptions with them;
   the golden files of what the model reads are regenerated, and their diff is checked to be `agent/` to `agents/`
   only. Test: `RoleCatalogTests` and `SkillLoaderSkillsTests` expect `agents/`, and fail first.
3. **The showroom flat, one provider.** `prompts/{business}/agent/{business}/` becomes `agents/{business}/`, the three
   identities share one provider, `AgentCatalog` reads its providers once each, and the subfolder overload goes.
   Test: a catalogue with the three showroom identities opens each voice and finds no path twice; a test of
   `AgentCatalog` with one provider given twice. Both fail first.
4. **The site's link to the principles.** `LouisAgent.Site.csproj` links `src/engine/LouisAgent.Core/shared/principles.md`.
   Test: `OrbiVoiceTests`, which reads it, and the site's build.
5. **The headers' levels, read from the new tree.** `EveryPromptHasAHeaderTests` finds each project's prompt folders
   at its root and reads a prompt's level from the first of `agents/`, `specialists/` and `minions/` on its path.
   Test: it fails first, finding no prompts, then holds every header.
6. **The docs, and closed.** Every project doc, guide and architecture page that names `prompts/` or `agent/`
   (*Build an identity*, *Build a pack*, *Add a skill*, the projects' docs, the core guide's project layout), their
   pictures redrawn, the parent plan's *Approved during the build*, the write-up's section, and this plan folded and
   deleted (`/finish-a-feature`). Test: the docs' tests.

## Concepts

- **Prompts as content** (steps 1 to 3): a prompt is a file the engine loads, and its path is its address, so a tree
  that reads the way the engine reads it is safer to change. GOAL.md skill 3, *Prompt design*.
- **One source, read once** (step 3): a provider shared by three identities is one thing, not three, and the
  catalogue's uniqueness check is what proves it. Skill 18, *Testing and shipping*.
